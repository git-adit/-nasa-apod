NASA APOD Viewer:

A web app that displays random Astronomy Picture of the Day images from NASA using the APOD API key.I can also put a specific date. It only allows photos though and no videos. I can make it customizable with the date and put a clear button. If it lands on  a day with a video, it displays "No picture today. There is a video".

I used a nasa api key, html, js, and css for this. I also used vs code for this.  I learned some more javascript and using API keys along with enviorment variables. I also learned how to show a loading message while waiting for the API to send back the image.
